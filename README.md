# Лабораторная работа: список товаров

## Цель

Научиться выводить данные из базы Room на экран с помощью RecyclerView.

## Что делает приложение

Приложение показывает список товаров. Для каждого товара отображаются название, цена и количество. При первом запуске в базу автоматически добавляются три примера.

## Основные части

- Product.java описывает один товар.
- ProductDao.java получает товары из базы.
- MainActivity.java загружает товары и подключает список.
- ProductAdapter.java помещает данные товара в строку списка.
- activity_main.xml содержит заголовок и RecyclerView.
- item_product.xml задаёт вид одной строки.

## Ход работы

1. Запустите приложение и посмотрите на список.
2. Откройте MainActivity.java и найдите примеры товаров.
3. Измените названия или цены примеров.
4. Запустите приложение. Если база уже содержит данные, очистите данные приложения в настройках эмулятора, чтобы увидеть изменённые примеры.
5. Откройте item_product.xml и измените размер текста или цвет строки.
